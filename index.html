API

One URL per logo. No key, no sign-up.

Every logo has a stable address derived from its channel ID, which never changes. Use it as is, or read logos.json to know which logos and variants exist.
  • Drop-in for iptv-org
    logos.json has the same fields as iptv-org's, plus country, variant and date.
  • Dark-screen ready
    A white version is published for every logo that needs one.
  • Editions included
    Regional editions get their own logo, or fall back to their channel.
API reference
# base: https://worldwide-tv-logos.github.io/database/
logos/ch_1r840gxdj5.png         # France 3, light screens
logos/ch_1r840gxdj5.white.png   # France 3, dark screens
logos/ch_dhk02zjhwa.png         # France 3 Alsace, an edition

const base = 'https://worldwide-tv-logos.github.io/database/'
const logos = await (await fetch(`${base}logos.json`)).json()

const logo = (iptv, { dark = false } = {}) =>
  logos.find(l => l.iptv === iptv && (l.variant === 'white') === dark)
  ?? logos.find(l => l.iptv === iptv)

logo('France3.fr', { dark: true }).url

curl -s https://worldwide-tv-logos.github.io/database/logos.json \
  | jq -r '.[] | select(.iptv == "France3.fr" and .variant == null) | .url'
Quality

Cleaned, checked, ready for any screen.

Logos come from contributors, iptv-org, iptv-epg, Wikidata and the channels' own websites. Each one goes through the same preparation, and old brandings are refused.
  • Transparent and trimmed
    White frames removed, SVG rendered at 1200 px, never upscaled.
  • Current branding only
    Dated with Wikidata and reviewed every week; a doubt is left out.
  • Readable everywhere
    Dark logos get a white version, white logos a dark one.
