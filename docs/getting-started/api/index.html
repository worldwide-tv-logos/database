logos.json

FieldTypeDescription
channelstringour channel ID, e.g. ch_1r840gxdj5: never changes, never reused
slugstringreadable name of the channel, e.g. france-3.fr (may change on a rename)
iptvstring or nullits iptv-org ID, e.g. France3.fr, or France3.fr@Alsace for an edition
countrystringcountry code (lowercase), e.g. fr
parentstring or nullfor an edition, our ID of its channel: its logo when the edition has none
variantstring or nullwhite for the version made for dark backgrounds, else null
width, heightintsize in pixels (longest side 500 to 2000)
formatstringalways PNG
urlstringaddress of the image
updatedstringdate of the last change of the image (YYYY-MM-DD), useful to refresh a cache

Examples

Logo of a channel or of an edition from its iptv-org ID, falling back to the channel logo:

const base = 'https://worldwide-tv-logos.github.io/database/'
const logos = await (await fetch(`${base}logos.json`)).json()

const find = (channel, dark = false) =>
  logos.find(l => l.channel === channel && (l.variant === 'white') === dark)
  || (dark && find(channel))                  // no white version: the logo itself

const byIptv = (iptv, dark = false) => {
  const own = logos.find(l => l.iptv === iptv)
  const parent = !own && logos.find(l => l.iptv === iptv.split('@')[0])
  return own ? find(own.channel, dark) : parent && find(parent.channel, dark)
}

byIptv('France3.fr@Alsace')?.url

From a TV guide ID:

const aliases = await (await fetch(`${base}aliases.json`)).json()
const a = aliases.find(x => x.epg_id === 'RTLtvi.be')
const logo = a && find(a.channel)

Command line:

curl -s https://worldwide-tv-logos.github.io/database/logos.json \
  | jq -r '.[] | select(.iptv == "TF1.fr" and .variant == null) | .url'

Good to know

  • An address never changes: a channel renamed or moved to another country keeps its ID, and a new image keeps the same address (check updated to refresh a cache).
  • Channel names, countries and categories of iptv-org: join on iptv with the iptv-org API.
  • A logo missing? Use the buttons on the channel pages, or the forms.

Use the logos
