## Files

All files are under `https://worldwide-tv-logos.github.io/database/`.

| File | Content | Use it to |
|---|---|---|
| [`channels.json`](#channelsjson) | every channel, its IDs and its logo | show a logo from our ID, an iptv-org or Wikidata ID |
| [`logos.json`](#logosjson) | every logo file, with its size and date | list the logos, refresh a cache |
| [`guides.json`](#guidesjson) | the channels of public TV guides matched with ours | show a logo from a TV guide ID |
| [`aliases.json`](#aliasesjson) | TV guide IDs confirmed by review | the sure part of `guides.json` |
| `logos/<id>[.white].png` | one logo (PNG, transparent) | display it |

::note
Plain files, no key and no rate limit of their own: download them once a day (they change at most once a night) rather
than at every request. New fields may be added; existing ones are never renamed or removed without changing
`version`.
::

## channels.json

`{"version": 1, "channels": [...]}`: every channel of the database, closed and merged ones included.

::field-group
  :::field{name="id" type="string" required}
  Our channel ID, e.g. `ch_dhk02zjhwa`. Never changes, never reused.
  :::

  :::field{name="slug" type="string" required}
  Readable name, e.g. `france-3-alsace.fr`. May change when the channel is renamed.
  :::

  :::field{name="name" type="string" required}
  Name of the channel.
  :::

  :::field{name="aliases" type="string[]" required}
  Its other names (may be empty).
  :::

  :::field{name="country" type="string" required}
  Country code, lowercase (`uk` for the United Kingdom).
  :::

  :::field{name="status" type="active | closed | merged" required}
  `merged`: the channel became `parent`.
  :::

  :::field{name="parent" type="string | null"}
  An edition's main channel, or the channel a merged one became.
  :::

  :::field{name="website" type="string | null"}
  Its website.
  :::

  :::field{name="iptv" type="string | null"}
  Its iptv-org ID: `France3.fr`, or `France3.fr@Alsace` for an edition.
  :::

  :::field{name="wikidata" type="string | null"}
  Its Wikidata ID (`Q` and digits), when it is known.
  :::

  :::field{name="logo" type="string | null"}
  Address of its logo. For an edition without a logo of its own, its channel's.
  :::

  :::field{name="logo_white" type="string | null"}
  Address of the version for dark backgrounds, when there is one.
  :::

  :::field{name="logo_from" type="string | null"}
  Set when `logo` is not the channel's own: the ID of the channel it comes from (its `parent`).
  :::
::

```json
{
  "id": "ch_dhk02zjhwa", "slug": "france-3-alsace.fr", "name": "France 3 Alsace", "aliases": [],
  "country": "fr", "status": "active", "parent": "ch_1r840gxdj5", "website": "https://www.france.tv/france-3/",
  "iptv": "France3.fr@Alsace", "wikidata": null,
  "logo": "https://worldwide-tv-logos.github.io/database/logos/ch_dhk02zjhwa.png",
  "logo_white": "https://worldwide-tv-logos.github.io/database/logos/ch_dhk02zjhwa.white.png",
  "logo_from": null
}
```

## logos.json

A list with one record per logo file (a white version is a record of its own).

::field-group
  :::field{name="channel" type="string" required}
  Our channel ID.
  :::

  :::field{name="slug" type="string" required}
  Readable name of the channel.
  :::

  :::field{name="iptv" type="string | null"}
  Its iptv-org ID.
  :::

  :::field{name="country" type="string" required}
  Country code, lowercase.
  :::

  :::field{name="parent" type="string | null"}
  For an edition, our ID of its channel.
  :::

  :::field{name="variant" type="string | null"}
  `white` for the version made for dark backgrounds, else `null`.
  :::

  :::field{name="width, height" type="int" required}
  Size in pixels (longest side 500 to 2,000).
  :::

  :::field{name="format" type="string" required}
  Always `PNG`.
  :::

  :::field{name="url" type="string" required}
  Address of the image.
  :::

  :::field{name="updated" type="string" required}
  Date of the last change of the image (`YYYY-MM-DD`): refresh a cached copy when it changes.
  :::
::

## guides.json

The channels of public TV guides matched with ours, rebuilt every night (details in
[TV guides](/docs/getting-started/tv-guides)):

```json
{"version": 1, "guides": {
  "iptv-epg-fr": {
    "TF1+1.fr": [{"channel": "ch_rxxkmndvjh", "score": 0.9, "how": "name"}],
    "France3-Alsace.fr": [{"channel": "ch_dhk02zjhwa", "score": 1.0, "how": "confirmed"}]
  }
}}
```

| Score | Meaning |
|---|---|
| :badge[1.0]{color="success"} | confirmed by review (an alias) |
| :badge[0.95]{color="success"} | the guide uses the channel's iptv-org ID |
| :badge[0.9]{color="success"} | one channel of the country only has this name |
| :badge[0.7]{color="warning"} | found by another name of the channel, or in another country |
| :badge[0.5]{color="error"} | ambiguous: each candidate is listed (three at most) |

## aliases.json

The guide IDs confirmed by review (they are also in `guides.json`, with the score 1.0).

::field-group
  :::field{name="epg_id" type="string" required}
  ID of the channel in the guide, e.g. `France3-Alsace.fr`.
  :::

  :::field{name="source" type="string" required}
  Short name of the guide, e.g. `iptv-epg-fr`.
  :::

  :::field{name="channel" type="string" required}
  Our channel ID it stands for.
  :::
::

## Examples

Logo of a channel from its iptv-org ID:

::code-group
```js [JavaScript]
const base = 'https://worldwide-tv-logos.github.io/database/'
const { channels } = await (await fetch(`${base}channels.json`)).json()
const channel = channels.find(c => c.iptv === 'France3.fr@Alsace')
channel?.logo
```

```python [Python]
import json, urllib.request

base = 'https://worldwide-tv-logos.github.io/database/'
channels = json.load(urllib.request.urlopen(base + 'channels.json'))['channels']
channel = next((c for c in channels if c['iptv'] == 'France3.fr@Alsace'), None)
print(channel and channel['logo'])
```

```bash [curl + jq]
curl -s https://worldwide-tv-logos.github.io/database/channels.json \
  | jq -r '.channels[] | select(.iptv == "France3.fr@Alsace") | .logo'
```
::

Logo of a channel from a TV guide ID:

::code-group
```js [JavaScript]
const { guides } = await (await fetch(`${base}guides.json`)).json()
const best = guides['iptv-epg-fr']['TF1+1.fr']?.[0]          // or look in every guide
const channel = best && best.score >= 0.9 && channels.find(c => c.id === best.channel)
channel?.logo
```

```python [Python]
guides = json.load(urllib.request.urlopen(base + 'guides.json'))['guides']
best = (guides.get('iptv-epg-fr', {}).get('TF1+1.fr') or [None])[0]
if best and best['score'] >= 0.9:
    print(next(c['logo'] for c in channels if c['id'] == best['channel']))
```

```bash [curl + jq]
curl -s https://worldwide-tv-logos.github.io/database/guides.json \
  | jq -r '.guides["iptv-epg-fr"]["TF1+1.fr"][0] | select(.score >= 0.9) | .channel'
```
::

## Good to know

::accordion
  :::accordion-item{label="Why is a logo null in channels.json?" icon="i-lucide-circle-help"}
  The channel has no logo here yet. It is listed on its country page with a **Request it** button, and the weekly
  searches keep looking for it.
  :::

  :::accordion-item{label="Can I join with the iptv-org data?" icon="i-lucide-circle-help"}
  Yes: `iptv` is the `id` of [iptv-org's channels](https://iptv-org.github.io/api/channels.json) (or `channel@feed`
  for its feeds). Categories, languages and broadcast areas are there.
  :::

  :::accordion-item{label="How do I refresh my copy?" icon="i-lucide-circle-help"}
  Download the files once a day; compare `updated` in `logos.json` to download again only the images that changed.
  :::

  :::accordion-item{label="Is there an API with a server?" icon="i-lucide-circle-help"}
  Not yet: everything is a static file, so it never goes down with a server. A read-only lookup API (a guide ID, a
  name or a whole XMLTV channel list in, channels and logos out) is planned.
  :::
::
