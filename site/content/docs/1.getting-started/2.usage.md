## Address of a logo

```txt
https://worldwide-tv-logos.github.io/database/logos/<id>[.white].png
```

`<id>` is our channel ID: `ch_` and 10 characters, shown on every [channel page](/countries). It never changes, even
when the channel is renamed or moves to another country, and is never reused.

| Logo | Address (after `https://worldwide-tv-logos.github.io/database/`) |
|---|---|
| TF1 (`ch_rxxkmndvjh`) | `logos/ch_rxxkmndvjh.png` |
| France 3 Alsace, an edition of France 3 (`ch_dhk02zjhwa`) | `logos/ch_dhk02zjhwa.png` |
| its version for dark backgrounds | `logos/ch_dhk02zjhwa.white.png` |

## Which file to show

::steps{level="3"}
### On a light background

Use the logo itself: `<id>.png`.

### On a dark background

Use `<id>.white.png` when it exists, else the logo itself. The white variant exists only for logos that would
be hard to read on a dark screen.

### For an edition

Use the edition logo when it exists, else the logo of its channel (`parent` in
[`logos.json`](/docs/getting-started/api)).
::

::tip
The list of the logos that exist, with their variants and sizes, is in [`logos.json`](/docs/getting-started/api),
with each channel's iptv-org ID: look a logo up there instead of probing addresses.
::

## Serving

Images are served by GitHub Pages (a CDN). The same paths also work under
`https://raw.githubusercontent.com/worldwide-tv-logos/database/main/`, which is not meant for heavy use.

An address never changes; a new image keeps the same address. Check the `updated` field of `logos.json` to refresh a
cache.
