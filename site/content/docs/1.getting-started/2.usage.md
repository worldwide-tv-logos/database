## Address of a logo

```txt
https://worldwide-tv-logos.github.io/database/logos/<cc>/<channel>[@<feed>][.white].png
```

| Logo | Address (after `https://worldwide-tv-logos.github.io/database/`) |
|---|---|
| TF1 | `logos/fr/TF1.fr.png` |
| France 3 Alsace (feed `Alsace` of `France3.fr`) | `logos/fr/France3.fr@Alsace.png` |
| its version for dark backgrounds | `logos/fr/France3.fr@Alsace.white.png` |

`<cc>` is the country code of the channel, in lowercase: the end of its ID (`TF1.fr` is in `fr`).

## Which file to show

::steps{level="3"}
### On a light background

Use the logo itself: `<channel>.png`.

### On a dark background

Use `<channel>.white.png` when it exists, else the logo itself. The white variant exists only for logos that would
be hard to read on a dark screen.

### For an edition

Use the edition logo when it exists (`<channel>@<feed>.png`), else the channel logo.
::

::tip
The list of the logos that exist, with their variants and sizes, is in [`logos.json`](/docs/getting-started/api):
look a logo up there instead of probing addresses.
::

## Serving

Images are served by GitHub Pages (a CDN). The same paths also work under
`https://raw.githubusercontent.com/worldwide-tv-logos/database/main/`, which is not meant for heavy use.

An address never changes while the channel keeps its iptv-org ID; a new image keeps the same address. Check the
`updated` field of `logos.json` to refresh a cache.
