## Endpoints

| Address | Content |
|---|---|
| `https://worldwide-tv-logos.github.io/database/logos.json` | every logo |
| `https://worldwide-tv-logos.github.io/database/channels.json` | every channel, with its IDs and logo |
| `https://worldwide-tv-logos.github.io/database/guides.json` | channels of public TV guides matched with ours |
| `https://worldwide-tv-logos.github.io/database/aliases.json` | TV guide (EPG) IDs confirmed by review |
| `https://worldwide-tv-logos.github.io/database/logos/<id>[.white].png` | one logo (PNG, transparent) |

## logos.json

| Field | Type | Description |
|---|---|---|
| `channel` | string | our channel ID, e.g. `ch_1r840gxdj5`: never changes, never reused |
| `slug` | string | readable name of the channel, e.g. `france-3.fr` (may change on a rename) |
| `iptv` | string or null | its iptv-org ID, e.g. `France3.fr`, or `France3.fr@Alsace` for an edition |
| `country` | string | country code (lowercase), e.g. `fr` |
| `parent` | string or null | for an edition, our ID of its channel: its logo when the edition has none |
| `variant` | string or null | `white` for the version made for dark backgrounds, else null |
| `width`, `height` | int | size in pixels (longest side 500 to 2000) |
| `format` | string | always `PNG` |
| `url` | string | address of the image |
| `updated` | string | date of the last change of the image (YYYY-MM-DD), useful to refresh a cache |

```json
{
  "channel": "ch_1r840gxdj5", "slug": "france-3.fr", "iptv": "France3.fr", "country": "fr", "parent": null,
  "variant": "white", "width": 512, "height": 437, "format": "PNG",
  "url": "https://worldwide-tv-logos.github.io/database/logos/ch_1r840gxdj5.white.png", "updated": "2026-11-21"
}
```

## channels.json

`{"version": 1, "channels": [...]}`, one record per channel of the registry (closed and merged ones included):

| Field | Type | Description |
|---|---|---|
| `id` | string | our channel ID |
| `slug` | string | readable name, e.g. `france-3-alsace.fr` (may change on a rename) |
| `name` | string | name of the channel |
| `aliases` | list | its other names |
| `country` | string | country code (lowercase) |
| `status` | string | `active`, `closed`, or `merged` (then `parent` is the channel it became) |
| `parent` | string or null | an edition's main channel, or the channel a merged one became |
| `website` | string or null | its website |
| `iptv`, `wikidata` | string or null | its iptv-org and Wikidata IDs |
| `logo`, `logo_white` | string or null | address of its logo and of the version for dark backgrounds |
| `logo_from` | string or null | for an edition without a logo of its own: the channel whose logo is given |

New fields may be added; existing ones are never renamed (`version` would change).

## guides.json

The channels of public TV guides (the iptv-epg guides of the followed countries, the xmltv.se IDs) matched with ours,
rebuilt every night: a guide that renames its IDs is followed without anything to do.
`{"version": 1, "guides": {guide: {guide channel ID: [{channel, score, how}]}}}`:

| Score | Meaning |
|---|---|
| `1.0` | confirmed by review (`aliases.json`) |
| `0.95` | the guide uses the channel's iptv-org ID |
| `0.9` | one channel of the country only has this name (quality and timeshift marks aside: `TF1 HD`, `TF1 +1`) |
| `0.7` | found by another name of the channel, or in another country |
| `0.5` | ambiguous: each candidate is listed (three at most) |

```json
{"version": 1, "guides": {"iptv-epg-fr": {
  "TF1+1.fr": [{"channel": "ch_rxxkmndvjh", "score": 0.9, "how": "name"}],
  "France3-Alsace.fr": [{"channel": "ch_dhk02zjhwa", "score": 1.0, "how": "confirmed"}]}}}
```

The search of the website finds a channel by its guide IDs from a score of 0.9.

## aliases.json

| Field | Type | Description |
|---|---|---|
| `epg_id` | string | ID of the channel in a TV guide, e.g. `RTLtvi.be` |
| `source` | string | short name of the guide, e.g. `iptv-epg-be` |
| `channel` | string | our channel ID it stands for |

## Examples

Logo of a channel or of an edition from its iptv-org ID, falling back to the channel logo:

```js
const base = 'https://worldwide-tv-logos.github.io/database/'
const logos = await (await fetch(`${base}logos.json`)).json()

const find = (channel, dark = false) =>
  logos.find(l => l.channel === channel && (l.variant === 'white') === dark)
  || (dark && find(channel))                  // no white version: the logo itself

const byIptv = (iptv, dark = false) => {
  const own = logos.find(l => l.iptv === iptv)
  const parent = !own && logos.find(l => l.iptv === iptv.split('@')[0])
  return own ? find(own.channel, dark) : parent && find(parent.channel, dark)
}

byIptv('France3.fr@Alsace')?.url
```

From a TV guide ID:

```js
const { guides } = await (await fetch(`${base}guides.json`)).json()
const { channels } = await (await fetch(`${base}channels.json`)).json()
const best = guides['iptv-epg-fr']['TF1+1.fr']?.[0]          // or look in every guide
const channel = best && best.score >= 0.9 && channels.find(c => c.id === best.channel)
channel?.logo
```

Command line:

```bash
curl -s https://worldwide-tv-logos.github.io/database/logos.json \
  | jq -r '.[] | select(.iptv == "TF1.fr" and .variant == null) | .url'
```

## Good to know

- An address never changes: a channel renamed or moved to another country keeps its ID, and a new image keeps the
  same address (check `updated` to refresh a cache).
- Channel names, countries and categories of iptv-org: join on `iptv` with the
  [iptv-org API](https://iptv-org.github.io/api/channels.json).
- A logo missing? Use the buttons on the [channel pages](/countries), or the
  [forms](https://github.com/worldwide-tv-logos/database/issues/new/choose).
