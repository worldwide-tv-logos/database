## Endpoints

| Address | Content |
|---|---|
| `https://worldwide-tv-logos.github.io/database/logos.json` | every logo |
| `https://worldwide-tv-logos.github.io/database/aliases.json` | TV guide (EPG) IDs that differ from iptv-org |
| `https://worldwide-tv-logos.github.io/database/logos/<cc>/<channel>[@<feed>][.white].png` | one logo (PNG, transparent) |

## logos.json

Same fields as [iptv-org's logos.json](https://github.com/iptv-org/api), so it can replace it as is, plus three
fields of its own.

| Field | Type | Description |
|---|---|---|
| `channel` | string | iptv-org channel ID, e.g. `France3.fr` |
| `feed` | string or null | iptv-org feed ID for an edition, e.g. `Alsace`; null for the channel itself |
| `in_use` | bool | always true (only current logos are kept) |
| `tags` | string[] | `["white"]` for the version made for dark backgrounds, else empty |
| `width`, `height` | int | size in pixels (longest side 500 to 2000) |
| `format` | string | always `PNG` |
| `url` | string | address of the image |
| `country` | string | country code of the channel (lowercase), e.g. `fr` |
| `variant` | string or null | `white` or null (same information as `tags`) |
| `updated` | string | date of the last change of the image (YYYY-MM-DD), useful to refresh a cache |

```json
{
  "channel": "France3.fr", "feed": null, "in_use": true, "tags": ["white"],
  "width": 512, "height": 437, "format": "PNG",
  "url": "https://worldwide-tv-logos.github.io/database/logos/fr/France3.fr.white.png",
  "country": "fr", "variant": "white", "updated": "2026-11-21"
}
```

## aliases.json

| Field | Type | Description |
|---|---|---|
| `epg_id` | string | ID of the channel in a TV guide, e.g. `RTLtvi.be` |
| `source` | string | short name of the guide, e.g. `iptv-epg-be` |
| `channel`, `feed` | string | the iptv-org IDs it stands for |

## Examples

Logo of a channel or of an edition, falling back to the channel logo:

```js
const base = 'https://worldwide-tv-logos.github.io/database/'
const logos = await (await fetch(`${base}logos.json`)).json()

const find = (channel, feed = null, dark = false) =>
  logos.find(l => l.channel === channel && l.feed === feed && l.tags.includes('white') === dark)
  || (dark && find(channel, feed))        // no white version: the logo itself
  || (feed && find(channel, null, dark))  // no logo for the edition: the channel logo

find('France3.fr', 'Alsace')?.url
```

From a TV guide ID:

```js
const aliases = await (await fetch(`${base}aliases.json`)).json()
const a = aliases.find(x => x.epg_id === 'RTLtvi.be')
const logo = a && find(a.channel, a.feed)
```

Command line:

```bash
curl -s https://worldwide-tv-logos.github.io/database/logos.json \
  | jq -r '.[] | select(.channel == "TF1.fr" and .tags == []) | .url'
```

## Good to know

- An address never changes while the channel keeps its iptv-org ID; a new image keeps the same address (check
  `updated` to refresh a cache).
- Channel names, countries and categories come from the
  [iptv-org API](https://iptv-org.github.io/api/channels.json): join on `channel`.
- A logo missing? Use the buttons on the [channel pages](/countries), or the
  [forms](https://github.com/worldwide-tv-logos/database/issues/new/choose).
