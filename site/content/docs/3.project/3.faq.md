## Using the logos

::accordion
  :::accordion-item{label="Is it free? Do I need a key?" icon="i-lucide-key"}
  Free, no key, no sign-up: plain files served by GitHub Pages. See [the API](/docs/getting-started/api).
  :::

  :::accordion-item{label="Will the address of a logo change?" icon="i-lucide-link"}
  No. It is made from our channel ID, which never changes, even when the channel is renamed. A new image of the logo
  replaces the old one at the same address.
  :::

  :::accordion-item{label="I have an iptv-org ID, not your ID" icon="i-lucide-fingerprint"}
  Look it up in [`channels.json`](/docs/getting-started/api#channelsjson) (`iptv`), or type it in the
  [search](/countries).
  :::

  :::accordion-item{label="I have the channel ID of my TV guide" icon="i-lucide-calendar-range"}
  [`guides.json`](/docs/getting-started/api#guidesjson) gives its channel with a score, and the
  [search](/docs/getting-started/tv-guides#try-it) finds it.
  :::

  :::accordion-item{label="Why is there no logo for the HD version?" icon="i-lucide-monitor"}
  HD, 4K and +1 versions show the same logo as the channel: use the channel's.
  :::

  :::accordion-item{label="Which file on a dark background?" icon="i-lucide-moon"}
  `<id>.white.png` when it exists, else `<id>.png`. See [Use the logos](/docs/getting-started/usage#which-file-to-show).
  :::
::

## Contributing

::accordion
  :::accordion-item{label="A channel is missing" icon="i-lucide-tv"}
  Add it with [channels/add](/docs/contribute/channels): it does not need to be in iptv-org.
  :::

  :::accordion-item{label="A logo is wrong or old" icon="i-lucide-replace"}
  Use **Replace logo** on the channel's page ([logos/edit](/docs/contribute)), with a link that shows the current
  logo.
  :::

  :::accordion-item{label="I don't have the image" icon="i-lucide-message-square-plus"}
  Use **Request it** on the channel's page: it is looked for, and you are told in the issue.
  :::

  :::accordion-item{label="Can I choose the ID of a channel I add?" icon="i-lucide-key-round"}
  No: it is made automatically, so that it never means anything and never needs to change.
  :::

  :::accordion-item{label="How long does it take?" icon="i-lucide-clock"}
  Checked within a minute, reviewed soon after, published the next night (03:00 UTC).
  :::
::

## The project

::accordion
  :::accordion-item{label="Which countries are covered?" icon="i-lucide-globe"}
  Every country of iptv-org is listed on the [website](/countries). The followed countries also get their new
  channels every night and the weekly searches for missing logos.
  :::

  :::accordion-item{label="Who maintains it?" icon="i-lucide-bot"}
  GitHub Actions and Claude, with maintainers for what is broken. See [How it is maintained](/docs/project/automation).
  :::

  :::accordion-item{label="Where is the code?" icon="i-simple-icons-github"}
  In the [repository](https://github.com/worldwide-tv-logos/database): the tools in Python (`uv run logos --help`),
  the website in Nuxt (`site/`).
  :::
::
