The repository runs by itself with
[GitHub Actions](https://github.com/worldwide-tv-logos/database/blob/main/.github/docs/workflows.md); Claude
(Anthropic's AI) reviews and prepares the changes following
[CLAUDE.md](https://github.com/worldwide-tv-logos/database/blob/main/CLAUDE.md), and maintainers keep the last word.

| When | What |
|---|---|
| Every request | automatic checks (IDs, image), then Claude's review: clear cases are approved, doubts go to a maintainer; a wanted logo is looked for by Claude |
| Every night | approved requests applied, data validated, website and API published |
| Sunday | harvest: new and better logos for every followed country, one pull request per country |
| Wednesday | hunt: a weekly slice of the channels still without a logo, every source including their website |
| Monday | changes on the iptv-org side (channel renamed, replaced or removed) applied |
| 1st of the month | activity report as an issue |

## Pull requests

Pull requests prepared by Claude contain data only (never code or workflows). They are merged when Claude finds every
logo right and the data validates; anything uncertain waits for a maintainer (label `needs:maintainer`).

## A new channel

A new iptv-org channel of a followed country is looked for the first Sunday after it appears. If no source has a
good logo, it stays in `missing/` and the Wednesday hunt tries again, including the channel's own website.

More for maintainers: [MAINTAINING.md](https://github.com/worldwide-tv-logos/database/blob/main/MAINTAINING.md).
