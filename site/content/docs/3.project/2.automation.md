The repository runs by itself with
[GitHub Actions](https://github.com/worldwide-tv-logos/database/blob/main/.github/docs/workflows.md). Claude
(Anthropic's AI) reviews the requests and prepares the changes following
[CLAUDE.md](https://github.com/worldwide-tv-logos/database/blob/main/CLAUDE.md); maintainers keep the last word.

## Calendar

All times are UTC.

| When | What |
|---|---|
| :badge[every request]{color="info"} | automatic checks (ID, image) within a minute, then review: clear cases are approved, a wanted logo is looked for |
| :badge[every night, 03:00]{color="success"} | approved requests applied; new, renamed and closed iptv-org channels followed; data validated; website and API published |
| :badge[Sunday]{color="neutral"} | harvest: new and better logos for every followed country, one pull request per country |
| :badge[Monday]{color="neutral"} | the week's changes at iptv-org (renamed, removed channels) in one issue, and the logos of renamed channels checked |
| :badge[Wednesday]{color="neutral"} | hunt: a weekly slice of the channels still without a logo, every source including their website |
| :badge[Thursday]{color="neutral"} | a slice of the published logos compared with the channels' websites |
| :badge[Friday]{color="neutral"} | a slice of the countries compared with the logos of the TV guides |
| :badge[1st of the month]{color="neutral"} | activity report as an issue |

## Channels

::steps{level="3"}
### New channels

A new iptv-org channel of a followed country is added every night with its own ID; a channel sent with the
[channels/add](/docs/contribute/channels) form, the night after its approval.

### Renamed or closed channels

A channel renamed at iptv-org keeps our ID and its logo; a closed one is marked closed. Its name and website follow
iptv-org, unless the channel was corrected here.

### Its logo

A new channel is looked for the first Sunday after it is added. If no source has a good logo, it stays in
`missing/<cc>.md` and the Wednesday hunt tries again, including the channel's own website.
::

## Pull requests

Pull requests prepared by Claude contain **data only**, never code or workflows. Claude decides every logo itself: it
keeps the right ones, replaces or rejects the others (a doubt is rejected, never published), and the pull request is
merged automatically once the data validates.

::callout{icon="i-lucide-life-buoy" color="warning"}
A maintainer is called only when something is broken: label `needs:maintainer`. A daily health check lists failed
workflows and pull requests waiting for too long in one issue labelled `health`.
::

More for maintainers: [MAINTAINING.md](https://github.com/worldwide-tv-logos/database/blob/main/MAINTAINING.md).
