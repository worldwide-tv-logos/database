## Pull request

```bash
uv sync
uv run logos import my-logos.csv     # CSV: channel,feed,origin  (origin: https URL or local file)
uv run logos validate
```

Commit `data/`, `logos/` and `sources/` together, with a commit message in English.

::warning
Never rename or edit files by hand: they are derived from `data/logos.csv` and the checks refuse anything else.
::

## data/logos.csv

| Field | Description | Example |
|---|---|---|
| `channel` | iptv-org channel ID | `France3.fr` |
| `feed` | iptv-org feed ID, empty for the channel itself | `Alsace` |
| `variant` | empty, or `white` (made automatically for mostly dark logos) | `white` |
| `width`, `height` | size of the PNG in pixels | `1200`, `412` |
| `origin` | where the original comes from: URL, or `issue #N` | `issue #12` |
| `added`, `updated` | dates (YYYY-MM-DD) | `2026-11-21` |

## data/aliases.csv

| Field | Description | Example |
|---|---|---|
| `epg_id` | ID of the channel in the guide | `France3-Alsace.fr` |
| `source` | short name of the guide | `iptv-epg-fr` |
| `channel`, `feed` | iptv-org IDs | `France3.fr`, `Alsace` |

## Repository layout

```txt
data/logos.csv       the index: channel, feed, variant, width, height, origin, added, updated
data/aliases.csv     guide IDs -> iptv-org IDs: epg_id, source, channel, feed
data/countries.csv   countries followed (missing/ lists, weekly harvest and hunt)
data/rejected.csv    logos refused in review, never proposed again
logos/<cc>/          the logos (PNG), named after their iptv-org ID
sources/<cc>/        the originals they were built from (same name, original extension)
missing/<cc>.md      iptv-org channels of the country that still have no logo here
site/                this website (Nuxt; its data is built by `logos export`)
worldwide_tv_logos/  the tools (`uv run logos --help`)
```
