For a handful of logos, the [forms](/docs/contribute) are simpler. For dozens, prepare a pull request with the tools
of the repository.

## Pull request

::steps{level="3"}
### Install

You need [uv](https://docs.astral.sh/uv/) and git.

```bash
git clone https://github.com/worldwide-tv-logos/database.git
cd database
uv sync
```

### List your logos

A CSV file with two columns: the channel and where its logo comes from.

```csv [my-logos.csv]
channel,origin
ch_dhk02zjhwa,https://example.org/france-3-alsace.svg
ch_rxxkmndvjh,https://example.org/tf1.svg
```

`channel` accepts our ID, a slug or an iptv-org ID; `origin` a direct `https://` link to the image.

### Import and check

```bash
uv run logos import my-logos.csv     # downloads, prepares and adds the logos
uv run logos validate                # the checks of the pull request
uv run logos sheet --changed         # contact sheets, dark and light tiles (temp/)
```

### Open the pull request

Commit `data/`, `logos/` and `sources/` together, with a message in English. The checks run on the pull request; it
is reviewed like a form request.
::

::warning
**Never add, rename or edit files by hand**: `logos/` and `sources/` are derived from `data/logos.csv`, and the checks
refuse anything else. Always go through `uv run logos` (`uv run logos --help` lists the commands).
::

## Data files

::code-tree{defaultValue="data/channels.csv"}
```csv [data/channels.csv]
id,slug,name,aliases,country,status,parent,website,added,updated
ch_1r840gxdj5,france-3.fr,France 3,,fr,active,,https://www.france.tv/france-3/,2026-11-23,
ch_dhk02zjhwa,france-3-alsace.fr,France 3 Alsace,,fr,active,ch_1r840gxdj5,https://www.france.tv/france-3/,2026-11-23,
```

```csv [data/external_ids.csv]
channel_id,source,external_id,method,added
ch_1r840gxdj5,iptv-org,France3.fr,import,2026-11-23
ch_dhk02zjhwa,iptv-org-feed,France3.fr@Alsace,import,2026-11-23
```

```csv [data/logos.csv]
channel,variant,width,height,origin,added,updated
ch_1r840gxdj5,,937,800,https://commons.wikimedia.org/wiki/Special:FilePath/France_3_2018.svg,2026-11-21,2026-11-22
ch_1r840gxdj5,white,937,800,https://commons.wikimedia.org/wiki/Special:FilePath/France_3_2018.svg,2026-11-21,2026-11-22
```

```csv [data/aliases.csv]
epg_id,source,channel
France3-Alsace.fr,iptv-epg-fr,ch_dhk02zjhwa
```

```csv [data/countries.csv]
code,name
at,Austria
be,Belgium
```

```csv [data/rejected.csv]
channel,url,reason,date
ch_t7yjbcfcsz,https://i.imgur.com/XpBgRo0.png,"the ""TV"" part is white, unreadable on a light background",2026-11-21
```
::

::field-group
  :::field{name="data/channels.csv" type="registry"}
  Our channels. `updated` is set when a channel was corrected here: the iptv-org follow-up no longer overwrites it.
  :::

  :::field{name="data/external_ids.csv" type="registry"}
  Other projects' IDs of each channel. `source`: `iptv-org`, `iptv-org-feed` (an edition), `wikidata`, and
  `iptv-org-former` / `iptv-org-feed-former` for IDs iptv-org no longer uses. `method`: `import`, `match` or `review`.
  :::

  :::field{name="data/logos.csv" type="index"}
  One row per logo file. `variant`: empty, or `white` (made automatically). `origin`: where the original comes from,
  a URL or `issue #N`.
  :::

  :::field{name="data/aliases.csv" type="index"}
  TV guide IDs confirmed by review.
  :::

  :::field{name="data/countries.csv" type="settings"}
  The followed countries: their new iptv-org channels are added every night, and they get the weekly searches and
  the `missing/<cc>.md` lists.
  :::

  :::field{name="data/rejected.csv" type="settings"}
  Logos refused in review, with the reason: never proposed again.
  :::
::

## Repository layout

```txt
data/                the data above (CSV)
logos/               the published logos: <channel id>.png and <channel id>.white.png
sources/             the originals they were made from (same name, original extension)
missing/<cc>.md      channels of a followed country that still have no logo
site/                this website (Nuxt; its data is built by `uv run logos export`)
worldwide_tv_logos/  the tools (`uv run logos --help`)
tests/               the tests (`uv run pytest`)
```
