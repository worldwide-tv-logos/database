An alias links the ID a TV guide (EPG) uses for a channel to the channel here, e.g. `France3-Alsace.fr` of the guide
`iptv-epg-fr` to France 3 Alsace (`ch_dhk02zjhwa`).

::callout{icon="i-lucide-info" color="info"}
**Most guide IDs need no alias**: they are matched automatically every night
([how](/docs/getting-started/tv-guides#how-guide-channels-are-matched)). An alias is useful when the match is missing,
ambiguous, or below 0.9: it then becomes a sure match (score 1.0) for everyone.
::

  :::

::field-group
  :::field{name="EPG ID" type="text" required}
  The ID of the channel in the guide: the `id` of `<channel id="…">` in the XMLTV file, e.g. `France3-Alsace.fr`.
  :::

  :::field{name="EPG source" type="text" required}
  Short name of the guide, e.g. `iptv-epg-fr`. For a guide of [`guides.json`](/docs/getting-started/api#guidesjson),
  use its name there.
  :::

  :::field{name="Channel ID" type="ch_ ID" required}
  Our ID of the channel (or of the edition) the guide ID stands for.
  :::
::

## Rules

- One guide ID points to **one** channel: to move it, remove it from the wrong channel first.
- The channel must have a logo of its own here (an alias leads to a logo).
- Link the most precise channel: the edition (France 3 Alsace) when the guide is the edition's and the edition has its
  own logo; otherwise its main channel.
