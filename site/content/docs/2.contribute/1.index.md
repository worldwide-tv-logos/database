## The quickest way

Open the channel on the [website](/countries) and use its buttons: **Add logo**, **Replace logo**,
**Report / remove** or **Request it**. The form opens on GitHub with the channel already filled in: you only give the
image.

::callout{icon="i-simple-icons-github" color="neutral"}
The forms are GitHub issues: a free GitHub account is needed. Everything you write in them is public.
::

## What happens next

::steps{level="3"}
### The channel ID

Every form takes **our channel ID** only: `ch_` and 10 characters, e.g. `ch_dhk02zjhwa` for France 3 Alsace, shown on
the channel's page (the buttons fill it in). A name, a slug or an iptv-org ID is refused with a hint, because they can
change. A channel that is not listed yet is [added first](/docs/contribute/channels).

### Automatic checks, within a minute

A bot reads the form, downloads the image and prepares it as it would be published. The issue gets the label
:badge[check:passed]{color="success"}, or :badge[check:failed]{color="error"} with a comment saying what to fix.
When the image is refused, a better file of the same logo is often found and proposed in a comment: just edit the
issue with it.

### Review

The logo is compared with the channel (its website, the logo on air), on a dark and a light preview. A request is
approved (:badge[approved]{color="info"}) unless there is a concrete reason against it, which is then explained in
the issue. Editing an approved request withdraws the approval: it is reviewed again.

### Published the next night

At 03:00 UTC the approved requests are applied one by one: the image is converted, committed, published on the
website and in the API, and the issue is closed with a summary of what changed.
::

## Image rules

::tabs
  :::tabs-item{label="Accepted" icon="i-lucide-circle-check"}
  - **SVG preferred**, else PNG, WebP or JPEG, from a direct `https://` link to the file.
  - At least **500 px** on its longest side once trimmed (images are never upscaled).
  - **Transparent background**. A white background is removed automatically, unless the logo needs it to stay
    readable.
  - The logo **currently on air**, the whole logo (not only the symbol, unless that is the logo used on screen).
  - A Wikipedia or Wikimedia Commons file page (`…/wiki/File:Logo.svg`) is read as the image itself.
  - A logo drawn in a web page can be pasted as `data:image/svg+xml,…`; then give the page in the notes.
  :::

  :::tabs-item{label="Refused" icon="i-lucide-circle-x"}
  - Too small, blurred, or a screenshot with a background.
  - An old branding (a logo dated as past by Wikidata, or a file named after a past period).
  - A link to a web page instead of the image, or a link that needs a login.
  - The same image for several different channels (a brand logo for numbered channels, e.g. Sport 1 and Sport 2).
  - The logo of another channel, or of a programme.
  :::

  :::tabs-item{label="Made for you" icon="i-lucide-wand-sparkles"}
  - Trimmed to the drawing, compressed without loss.
  - A **white version** for dark screens when the logo is dark, a dark version when it is made of white letters.
  - The original is kept in the repository (`sources/`), next to the published PNG.
  :::
::

## Questions

::accordion
  :::accordion-item{label="My request got check:failed" icon="i-lucide-circle-help"}
  Read the bot's comment: it says what is wrong (ID, image size, a web page instead of an image) and often proposes
  a better image. Edit the issue (the pencil of its first message): it is checked again automatically.
  :::

  :::accordion-item{label="How long until my logo is online?" icon="i-lucide-circle-help"}
  Once approved, the next night (03:00 UTC), then a few minutes for the website. The issue is closed when it is done.
  :::

  :::accordion-item{label="The channel has a logo, but an older one" icon="i-lucide-circle-help"}
  Use **logos/edit** with the current logo and a reason with a link that shows it (the channel's website). The
  address stays the same; `updated` changes in `logos.json`.
  :::

  :::accordion-item{label="Do I need a TV guide ID?" icon="i-lucide-circle-help"}
  No. Guide IDs are matched automatically every night; an alias only helps when the automatic matching is not sure.
  :::
::
