## The quickest way

Open the channel on the [website](/countries) and use its buttons: **Add logo**, **Replace logo**,
**Report / remove** or **Request it**. The form opens with the channel already filled in.

::steps{level="3"}
### Find the channel

Its ID here, e.g. `ch_dhk02zjhwa` for France 3 Alsace, shown on its channel page: the forms take this ID only, and
the buttons of the channel page fill it in.

### Submit the logo

Open the [logo form](https://github.com/worldwide-tv-logos/database/issues/new?template=01_logos_add.yml) with a
direct `https://` link to the image.

### Automatic checks

A bot checks the request within a minute: label `check:passed`, or a comment explaining what to fix. Then the
request is reviewed.

### Applied the next night

The nightly run downloads the image, converts it, commits it and closes the issue with a summary.
::

::note
A logo must be on a **transparent background** (a white background is removed automatically), at least **500 px** on its
longest side; **SVG is preferred**. Use the version currently on air.
::

## All the forms

| Form | Use it to | Applied by the bot |
|---|---|---|
| [logos/add](https://github.com/worldwide-tv-logos/database/issues/new?template=01_logos_add.yml) | add the logo of a channel that has none here | yes |
| [logos/edit](https://github.com/worldwide-tv-logos/database/issues/new?template=02_logos_edit.yml) | replace a logo (new branding, better quality, wrong logo) | yes |
| [logos/remove](https://github.com/worldwide-tv-logos/database/issues/new?template=03_logos_remove.yml) | remove a wrong or outdated logo | yes |
| [logos/request](https://github.com/worldwide-tv-logos/database/issues/new?template=04_logos_request.yml) | ask for a logo when you do not have the image | it is looked for |
| [aliases/add](https://github.com/worldwide-tv-logos/database/issues/new?template=05_aliases_add.yml) | link the ID a TV guide uses to a channel | yes |
| [aliases/remove](https://github.com/worldwide-tv-logos/database/issues/new?template=06_aliases_remove.yml) | remove a wrong alias | yes |
| [channels/add](https://github.com/worldwide-tv-logos/database/issues/new?template=07_channels_add.yml) | add a channel that is not listed yet (in iptv-org or not) | yes |
| [channels/edit](https://github.com/worldwide-tv-logos/database/issues/new?template=08_channels_edit.yml) | correct a channel: new name, website, closed, main channel, IDs | yes |

## A channel that is not on the website

Add it with the [channels/add](https://github.com/worldwide-tv-logos/database/issues/new?template=07_channels_add.yml)
form (name, country, website; for a regional version, its main channel), also linked on every country page: it gets
its own ID the night after approval, without waiting for iptv-org. Then add its logo, or let the weekly search find
it. A renamed channel is corrected with channels/edit, never added again: it keeps its ID and its logo.

## A channel without a TV guide ID

Nothing to do: a guide ID is optional. An alias only helps to find a logo from the ID a guide uses.
