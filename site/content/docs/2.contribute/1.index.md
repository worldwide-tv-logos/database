## The quickest way

Open the channel on the [website](/countries) and use its buttons: **Add logo**, **Replace logo**,
**Report / remove** or **Request it**. The form opens with the channel already filled in.

::steps{level="3"}
### Find the channel

Its iptv-org ID, e.g. `France3.fr`, and the feed ID for a regional version, e.g. `Alsace`.

### Submit the logo

Open the [logo form](https://github.com/worldwide-tv-logos/database/issues/new?template=01_logos_add.yml) with a
direct `https://` link to the image.

### Automatic checks

A bot checks the request within a minute: label `check:passed`, or a comment explaining what to fix. Then the
request is reviewed.

### Applied the next night

The nightly run downloads the image, converts it, commits it and closes the issue with a summary.
::

::note
A logo must be on a **transparent background** (a white background is removed automatically), at least **500 px** on its
longest side; **SVG is preferred**. Use the version currently on air.
::

## A channel that is not in iptv-org

Every logo is attached to an iptv-org channel, so that its name is stable and shared with guides and playlists.
Submit both requests the same day:

1. [add the channel to iptv-org](https://github.com/iptv-org/database/issues/new?template=01_channels_add.yml), and
   note the channel ID it will get (name without spaces + country code, e.g. `MyChannel.fr`);
2. submit the logo here with that exact ID.

The bot checks the image and labels the request `waiting:iptv-org`; the logo is added as soon as iptv-org has the
channel, with nothing else to do.

## A channel without a TV guide ID

Nothing to do: a guide ID is optional. Logos are found by iptv-org ID; an alias is only useful when a guide uses a
different ID for the channel.
